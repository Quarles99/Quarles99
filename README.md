## ⚔️ Sigilwar

A Discord bot autobattler with persistent rosters. You build a roster of fantasy characters, send them on idle hunts to level up and find gear, then challenge anyone in your server to async 1v1 PvP. Each fight is replayed in the channel one blow at a time as pixel-art combat scenes. It has three classes, gear in five rarity tiers, crafting, a daily dungeon, and a leaderboard for each server. It's **live in production** as a Node.js + SQLite bot on a self-hosted VPS. The source is private. · [Terms](https://quarles99.github.io/sigilwar-legal/terms) · [Privacy](https://quarles99.github.io/sigilwar-legal/privacy)

## 🎮 [Quasimorph-Coop](https://github.com/Quarles99/Quasimorph-Coop)

A C# mod that adds a second fully player-controlled merc to Quasimorph missions, with turns played either hotseat or online over Steam with a friend. The game assumes exactly one player, so the mod swaps whichever merc is active into the game's single player slot, and both players' games run the same simulation in lockstep and resync themselves if they ever drift. It's at **milestone 3**: combat, inventory, looting, stations and extraction all sync, and between missions the friend equips their own merc on the host's ship. It's an experimental release on the [Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3826739727) and has only been tested on one machine so far.

## 🏰 Gauntlet

A cooperative tactical dungeon crawler built as a Discord Activity. Up to four players fight 16×16 turn-based battles, then extract or go down together. There's a seeded Daily run, and the game has its own characters, gear, talents and scoreboards. It's **in development**, and the source is private.

## 🗡️ [wh3-ai-spectator](https://github.com/Quarles99/wh3-ai-spectator)

A Total War: WARHAMMER III mod that gives both sides of a battle to a smarter AI so you can spectate. It's designed to be deterministic so multiplayer battles don't desync. **Early scaffold:** the pure-Lua helper libraries are unit tested outside the game, and it hasn't run in game yet.

## 🛖 [Outpost Survival](https://github.com/Quarles99/outpost_survival)

A grimdark base-building survival prototype in Godot 4.7. Citizens pick jobs through Gale-Shapley matching, and there are real production chains, skills and happiness, a day/night cycle, and night-time orc raids.

## 🎧 [Bard_Bot](https://github.com/Quarles99/Bard_Bot) (archived)

A self-hosted Discord music bot on `discord.py` + `wavelink` + Lavalink. It includes a **custom Java DSP plugin** (a two-stage loudness leveler and limiter) that evens out volume across tracks mastered at different levels. It's finished and was decommissioned in August 2026. The [postmortem](https://github.com/Quarles99/Bard_Bot/blob/main/POSTMORTEM.md) explains why.
